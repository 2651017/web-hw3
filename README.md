# 실습과제 #3 : 살아 움직이는 영화 보드

- 이름 / 학번 : 김정희 / [학번 입력]
- 사이트 주소 : https://2651017.github.io/web-hw3/
- 출발점 : 내 #1, #2 저장소
- 사용한 API : TMDB(포스터, 영화 정보), KOBIS(일별 박스오피스, 기준일 2026-10-30)

## 구현 항목 체크(기능 체크표)

| 요구사항 | 상태 | 한 줄 메모 |
|---|---|---|
| 1 렌더링 | 완료 | 카드 10장 렌더링, `data-type` 속성 설정 |
| 2 검색 | 완료 | 영화 제목 검색 |
| 3 정렬 3종 | 완료 | 평점순·최신 개봉순·제목 가나다순 |
| 4 보기 필터와 getView | 완료 | 검색 → 보기 필터 → 정렬 순서로 적용 |
| 5 찜과 저장 | 완료 | `localStorage` 저장 및 새로고침 후 복원 |
| 6 빈 결과 | 완료 | 결과가 없으면 안내 문구 표시 |
| 7 상세 대화상자 | 완료 | 카드 클릭으로 상세 표시, 닫기 버튼 지원 |
| 8 인라인 이벤트 속성 없음, 콘솔 오류 0 | 완료 | 인라인 이벤트 없음, 브라우저 콘솔 오류 없음 |
| 보너스(했다면 이름) | 완료 | 포스터 누락 시 대체 표지 |

## 어려웠던 점 3가지와 해결

1. 검색·보기·정렬 조건을 함께 적용해야 했습니다. `getView()`에서 검색, 필터, 정렬 순서로 처리했습니다.
2. 화면을 다시 그리면 찜 표시가 초기화될 수 있었습니다. 찜 목록을 `localStorage`에 저장하고 렌더링 때 반영했습니다.
3. 카드 클릭과 찜 버튼 클릭을 구분해야 했습니다. 보드 이벤트 위임과 찜 버튼 판별 후 조기 반환으로 상세 창이 열리지 않게 했습니다.
