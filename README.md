# 내 영화 보드

## 프로젝트 소개

TMDB 영화 정보와 KOBIS 박스오피스 데이터를 함께 보여주는 영화 보드입니다.

## 주요 기능

- 영화 제목 검색
- 내 영화와 박스오피스 필터
- 평점순, 최신 개봉순, 제목순 정렬
- 영화 상세 정보 대화상자
- 찜 목록 저장 및 새로고침 후 복원

## 실행 방법

`index.html`을 브라우저에서 엽니다. 포스터와 웹 폰트를 불러오려면 인터넷 연결이 필요합니다.

## 데이터 출처

- 영화 정보 및 포스터: TMDB
- 박스오피스 데이터: KOBIS (기준일 2026-10-30)
